# UI Spec (Markdown Pages)

This folder contains Markdown UI specification pages for role-based dashboards and key workflows. Use these pages as a lightweight clickable spec for frontend implementation and product reviews.

Structure:
- `navigation.md` — role navigation menus and top-level routes
- `super-admin.md`, `admin.md`, `receptionist.md`, `doctor.md`, `nurse.md`, `lab-technician.md`, `pharmacist.md`, `cashier.md`, `hospital-manager.md`, `patient.md` — role-specific pages

How to use:
- Open `navigation.md` and click the links to jump to each role page.
- Each role page lists dashboard widgets, primary pages, routes, and example UI elements.
