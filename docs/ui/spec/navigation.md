Top-level routes (examples):
- `/dashboard` — role-specific dashboard
- `/patients` — patients list/search
- `/patients/:id` — patient profile
- `/appointments` — appointment calendar/list
- `/billing` — billing homepage (cashier/admin)
- `/pharmacy` — pharmacy module
- `/lab` — lab module
- `/reports` — reports
- `/settings` — system or user settings
